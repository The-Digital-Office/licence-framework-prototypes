# licence-framework-prototypes

Clickable prototypes of the Licence Audit and Allocation Framework from the
LocalGov M365 Foundations Programme. They show how the framework could help
Scottish councils make consistent, defensible Microsoft 365 licensing
decisions, and are shared so councils can try them and give feedback.

> [!NOTE]
> These are prototypes for review. They are still in development and are not
> final guidance.

The prototypes are published at
<https://the-digital-office.github.io/licence-framework-prototypes/>.

| Prototype | File | What it does |
|---|---|---|
| Organisational baseline tool | [`baseline.html`](baseline.html) | Works through a structured set of questions to produce a baseline statement for the organisation. |
| Allocation flow | [`allocation.html`](allocation.html) | Tests whether a person meets the six F3 gate conditions, and works through the device licensing checks. |

## Getting started

Open the published site above, or open `index.html` in a web browser. Each
page is a single self-contained HTML file with no build step, server or
external dependencies. Nothing entered is sent anywhere.

To change a prototype, edit its HTML file and open a pull request. The site
is republished automatically when the change is merged into `main`.
